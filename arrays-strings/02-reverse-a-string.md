## Problem: Reverse a String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

### Approach

Use two pointers, one starting from the beginning and one from the end.
Swap the characters at these positions and move both pointers toward the center.
Continue until the pointers meet.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

The string is reversed in-place without using another array.
Two local test cases were executed successfully.
